# 0004 「总是」按路径记，不按“族”记

- 状态：生效
- 日期：2026-10-11（首版） / 2026-11-15（改为实时缓存）

## 背景

最初「该对话中总是允许」记录的是“本对话允许读（或写）”这一布尔量。
后果：用户为了读一个文件点了“总是”，整个磁盘的读都被放开了；面板里也看不到任何行（面板列的是按路径的白名单），
用户的原话是「额外可读文件显示还是零，是不是你申请的没有写入那个列表」。

## 决策

「总是」只记录**本次请求涉及的路径**（`grantTargetsOf` 得到目录，目录覆盖其下全部），读写分族、互不派生。
面板按行展示，可逐行撤销。

## 后果

- 最小授权：授权一个文件不会顺带放开它所在的整个磁盘（实际记的是所在目录，见下）。
- 用户可见可撤销：面板里能看到“我到底授权了什么”。
- 已知粒度问题：记的是**目录**而不是单个文件，所以授权 `/etc/hostname` 后再读 `/etc/passwd` 不再询问。
  这是刻意的取舍——按文件记会让同目录下的每个文件都问一次，体验不可接受。
