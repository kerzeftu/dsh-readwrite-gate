# 0002 按真实路径判定，不用命令形态启发式

- 状态：生效
- 日期：2026-10-31（重写解析器）

## 背景

早期实现按“命令看起来危不危险”判定：某些命令整体按读、某些整体按写、未知命令 opaque。
用户明确否决：「我要求按真实路径判断」。

## 决策

所有判定都归结为“这次调用读了哪些绝对路径、写了哪些绝对路径”，再与工作区/临时区比较：

- shell 用 `tokenizeShell` + `walkScript` 真正解析重定向、包装命令、脚本体、赋值展开；
- 工具调用递归提取路径（含嵌套结构）；
- 解析不出来才退化为 opaque，并按 `opaquePolicy` 处理。

## 后果

- 规则可解释：拒绝文案里能写出具体路径。
- 解析器复杂、边角多（`cp` 目标顺序、`dd if=/of=`、`-f` 不吃参数、`file://`），需要持续补断言。
- 仍然不是内核级校验：词法折叠 + realpath，做不到 `openat2` 的语义。

## 替代方案

命令白/黑名单：实现快，但“为什么拦我这条”无法回答，且未知命令一律受阻，误伤严重。
