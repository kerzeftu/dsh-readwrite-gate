# 0005 临时区视为内部

- 状态：生效
- 日期：2026-11-15

## 背景

平台沙箱在可写模式下的可写根是 `[workspaceRoot, '/tmp', os.tmpdir()]`——`/tmp` 本来就能写。
但插件的判定只看工作区根，于是每次读写 `/tmp` 都弹授权页。
用户反馈：「每次都会请求读写 /tmp 说明有问题……/tmp 要默认可读取可写入」。

## 决策

`insideTempArea()` 把 `/tmp` 与 `os.tmpdir()` 视为内部：不参与“是否区外”的判断，因此不弹页。
只接受绝对路径（相对词先按 `workdir`/`cwd` 定基），避免“区外相对路径被临时区吸收”的旧 bug。

## 后果

- 两层围栏一致：沙箱允许写的地方，插件不再多问一次。
- 仍然受级别约束：无权限、只读时 `/tmp` 也不可写（`scope: none` 先于临时区判定）。
- `/tmp` 会被系统清理，不能作为唯一副本的存放地（这是使用侧注意事项，不是插件行为）。

## 替代方案

把临时区做成可配置项：目前不需要，且增加配置面；若将来要支持自定义 temp 根，再加。
