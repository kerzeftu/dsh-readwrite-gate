## 路径约定

示例中的 `<repo-path>` 指本地插件目录的绝对路径，`<profile-dir>` 指 Harness profile 目录，`<dsh-dir>` 指 DSH 版本目录，`~` 指用户主目录。使用命令前，请替换相应占位符。

未特别说明的仓库文件路径均相对于仓库根目录。技术文档通常引用文件名和函数名，不依赖固定代码行号。
