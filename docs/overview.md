# 项目概览

司门（`dsh-readwrite-gate`）是 DeepSeek Harness（DSH）的文件访问权限插件。它增加“无权限”和“工作区内读写”两种档位，并为受限范围之外的读取、修改操作提供分别授权的提示。

## 适用场景

如果希望模型只处理当前项目，可以选择“工作区内读写”。模型可直接读取、修改工作区和临时目录中的文件；读取其他路径时需要授权。

如果允许模型读取其他目录，但仍希望限制写入范围，可以选择“工作区内编辑”。这两种档位的写入范围相同，区别在于是否限制读取。

“只读”适合检查文件而不修改内容。“无权限”默认禁止读取和修改，但用户手动添加的读白名单仍然有效。“完全访问”不限制文件路径，应谨慎使用。

## 与 DSH 沙箱的关系

在已验证的 DSH 版本中，文件沙箱主要限制写入。司门补充读取范围和授权判断，不替代沙箱：即使用户同意了修改请求，实际写入仍可能被沙箱拒绝。

司门依赖工具参数和命令路径分析，不是操作系统级的隔离机制。复杂脚本的内部访问未必能够完整识别，详见[路径分析](path-analysis.md)中的已知边界。

## 五档一览

| 权限档 | 预设 id | 读 | 写 | 平台沙箱 |
|--------|---------|----|----|----------|
| 无权限 | `no-access` | 默认禁止；手动添加的读白名单除外 | 禁止 | `read-only` |
| 工作区内读写 | `workspace-access` | 工作区 + 临时目录；以外逐次授权 | 工作区 + 临时目录；以外弹页后仍被沙箱拒绝 | `workspace-write` |
| 只读 | `read-only` | 任意路径 | 全拒 | `read-only` |
| 工作区内编辑 | `workspace-write` | 任意路径 | 工作区 + 临时目录；以外逐次授权 | `workspace-write` |
| 完全访问 | `danger-full-access` | 任意路径 | 任意路径 | `danger-full-access` |

这些档位并非逐级包含。例如，“只读”可读取任意路径但不能修改文件；“工作区内读写”可以修改工作区内的文件，但读取区外路径需要授权。预设与内部配置的对应关系见[权限与范围](levels-and-scopes.md)。

## 术语

- **工作区**：当前会话使用的工作区根目录，由 DSH 提供，不一定是用户主目录。
- **临时目录**：`/tmp` 和系统临时目录。在允许工作区读写的档位下，司门将它们纳入允许范围；“无权限”和“只读”仍遵守各自的限制。
- **额外路径**：通过面板、命令或授权提示添加的路径，可在“额外可读写文件”面板中查看和撤销。
- **权限档位**：输入框权限菜单中的选项，如“只读”“工作区内读写”。
- **级别与范围**：插件的内部配置。`level` 表示总体限制方式，`readScope` 和 `writeScope` 分别指定读取、修改范围，日常使用无需修改这些字段。
- **无法完整分析的命令（opaque）**：不能仅凭命令文本确定全部访问路径的脚本或程序，按运行目录或配置的拒绝策略处理。
- **授权提示**：使用 DSH 问题面板显示的访问请求，提供拒绝、单次允许和本对话内持续允许三种选择。

## 使用前须知

- 额外授权不会绕过 DSH 沙箱，也不能解除“只读”等档位的写入限制。
- 读取授权不会自动授予修改权限；可写路径会同时显示在面板的读栏中。
- 授权由用户确认，模型不能自行授予权限。
- 授权不跨 Harness 进程保存。重启后的首次越界访问需要重新询问，详见[授权说明](authorization.md)。
